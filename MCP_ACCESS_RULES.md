# MCP Access Rules for Antigravity

This file records the rules of engagement for the AI assistant (Antigravity) regarding access to the Obsidian vaults.

## Rules
1. **Read-Only Access**: Antigravity has access to both Tim's and Chrisann's vaults for context and assistance. However, this access is strictly **Read-Only**.
2. **Forbidden Actions**: Antigravity must not use any tools that create, modify, or delete files in the vaults, even if the MCP server exposes them.
3. **Allowed Actions**: Antigravity may freely use tools that retrieve information, such as searching notes, listing files, and reading note content.

These rules ensure data safety and prevent accidental modification of your knowledge base.
